# Talismans — расходуемые тотемы бессмертия

Плагин для **Purpur 1.20.4** (Paper-fork, подойдёт и обычный Paper/Spigot 1.20.4).
Талисман срабатывает в момент, когда тотем спасает игрока от смерти: смертельный
урон отменяется, талисман расходуется (один предмет), эффект применяется.

## Талисманы

| ID | Название | Материал | Эффект при срабатывании |
|---|---|---|---|
| `swift` | Талисман Скорохода | Тотем Бессмертия | Скорость II — 5 сек |
| `sea_spirit` | Талисман Морского Духа | Тотем Бессмертия | Подводное дыхание — 10 сек, Грация дельфина — 8 сек |
| `fire_shield` | Талисман Огненного Щита | Тотем Бессмертия | Огнестойкость — 8 сек, Скорость I — 5 сек |
| `barrier` | Талисман Барьера | Тотем Бессмертия | Отбрасывает игроков вокруг владельца (радиус/сила настраиваются) + Скорость I — 5 сек |
| `end` | Талисман Энда | Тотем Бессмертия | Случайный телепорт на 8 блоков в направлении взгляда |

Все талисманы — обычные **Тотемы Бессмертия** из ванильного майнкрафта, различаются
именем, лором и внутренней PDC-меткой (переживает перезаход и стак).

## Срабатывание

- Основная логика — в `EntityDamageEvent`: если итоговый урон (с учётом
  поглощения жёлтыми сердцами) убивает игрока, событие отменяется, талисман
  расходуется, эффекты выдаются, играется звук тотема и частицы.
- Ванильный **Тотем Бессмертия** (обычный, без PDC-метки) в руке имеет приоритет:
  если бы ваниль съела именно его — талисман не расходуется. Талисман же в руке
  ваниль съесть не может: наш обработчик срабатывает первыми и отменяет урон,
  поэтому ванильный тотем никогда не «съедает» талисман вместо его эффекта.
- Игроки без права `talismans.use` талисманами не пользуются.
- Исключение: смерть от `/kill` обходит систему урона — талисман в этом случае
  не сработает (API не позволяет отменить событие смерти).

## Команды

```
/talisman give <игрок> <тип> [кол-во]   — выдать талисманы
/talisman list                          — список типов
/talisman reload                        — перезагрузить config.yml
```

Алиасы: `/talis`. Права: `talismans.give`, `talismans.reload` (op),
`talismans.use` (доступно всем).

## Сборка

```bash
mvn -DskipTests package
```

Готовый jar: `target/Talismans-1.0.0.jar` → в папку `plugins/` сервера.

Сборка: Maven, Java 17, **purpur-api 1.20.4-R0.1-SNAPSHOT**
(репозиторий `https://repo.purpurmc.org/snapshots`).

## Настройка

Всё в `plugins/Talismans/config.yml`: радиус и сила отбрасывания у Барьера,
дистанция и разброс телепортации у Энда, а также сообщения (`&`-цвета).
